# Student Management System (Hệ thống Quản lý Sinh viên)

> **Môn học:** Công nghệ phần mềm nâng cao (Advanced Software Engineering)  
> **Trường:** Đại học Bách Khoa TP.HCM (HCMUT)

Dự án này là bài tập thực hành xây dựng một Web Application cơ bản sử dụng **Java Spring Boot**, bao gồm các kỹ năng từ khởi tạo dự án, xây dựng REST API, Server-Side Rendering (SSR) đến triển khai (Deployment).

## 🛠 Công nghệ sử dụng
* **Ngôn ngữ:** Java 17+
* **Framework:** Spring Boot 3.x
* **Build Tool:** Maven
* **Database:** SQLite (Lab 1-3), PostgreSQL (Lab 4-5)
* **Template Engine:** Thymeleaf (cho giao diện SSR)
* **Frontend:** HTML5, CSS3
